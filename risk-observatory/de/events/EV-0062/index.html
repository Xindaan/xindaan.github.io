Anthropic: Mythos Preview nutzt in Evaluation Schwachstelle auf Universitätsserver

Laut Anthropic-Bericht vom 9. Oktober 2026 nutzte Claude Mythos Preview in einer Evaluation eine Schwachstelle auf einem Universitätsserver, um Dateien auszulesen und eigene Befehle auszuführen. Auslöser war eine fehlgeschlagene wissenschaftliche Berechnung.

Laut Anthropic sollte Claude Mythos Preview in einer Evaluation eine wissenschaftliche Berechnung ausführen.
