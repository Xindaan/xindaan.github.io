29:Tc93,Language models may assist with extraction, classification and summarisation. An AI-generated summary is, however, never evidence in itself: it can only be recorded as the provenance of a claim. A claim counts as supported only once it has been checked against the original source and the location is recorded with a verbatim quote. This check is performed by AI models: one model reads the archived source text and proposes location, quote and status; a second, independent model cross-checks. A script ensures every quote appears verbatim in the source. If a claim has several parts, each part gets its own quote; the claim counts as supported only if the quotes together show every part, and this is exactly what the second model checks. That a source does not mention something cannot be shown by any quote: such claims count at most as partially supported or as unverifiable and carry a fixed note. A teaser behind a paywall does not count as source text; checks use only the full article. The check applies to the German wording of a claim. The English pages show claims and uncertainty notes as machine translations by a language model, labelled as such and with the verified German wording available to expand; a script checks each translation for the same digit sequences, the German number words up to twelve and orders of magnitude (millions, billions), but not for order or meaning, and no second model reviews it. If the German or the English wording is changed afterwards, the translation is no longer shown until it is renewed. Locators stay as in the source. If a website blocks automated retrieval, a browser loads the page; the saved text is then marked as a browser retrieval and checked the same way. If the browser is blocked too, the operator can save the page from their own browser in an attended session; a script checks the origin note in the saved file against the source address, and the text is marked as a Chrome retrieval and checked the same way. If the two models disagree, a third model judges independently; only what two models agree on counts, otherwise the claim is not supported. If the second model shares the verdict but finds the quote insufficient, and the third model reaches the same verdict, the third model’s quote is used, provided it appears verbatim in the source. The verification note records which models checked. Models likewise assess each event (evidence quality, event type, attribution, texts): one model proposes, a second rates blind and checks every text against the supported claims, a third resolves differences. The same procedure produces the risk assessments per dimension, the study and governance entries and the situation report. Assessments for earlier cut-off dates are retrospective: they rely only on events that were publicly known by that date. Every public build checks the quotes in verified event evidence against locally saved source texts; locators and provenance must be present and fixed quality caps must be met. This confirms that the passage occurs in the saved source, not that the source is true or a model assessment is correct.
