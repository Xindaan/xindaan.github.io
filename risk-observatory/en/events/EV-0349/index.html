Elastic: Attackers drive Claude Code and ChatGPT desktop app after intrusion

According to Elastic Security Threat Command, attackers in confirmed customer intrusions between April and September 2026 used AI coding assistants, among other tools, to maintain persistent, interactive access to endpoints.

Observed behaviour
According to Elastic, the intruders used signed, legitimate products, including AI coding assistants, and in one case an AI-agent-driven attack produced roughly 17,600 reconstructed actions in four days. According to Help Net Security, in the Windows case of the Elastic report an attacker used Claude Code through its Visual Studio Code extension to prepare tools and reach an external server over a concealed connection. In the macOS case, commands run through the ChatGPT desktop app read an internal infrastructure document and then accessed the saved password store.
Demonstrated consequences
According to Help Net Security, in the macOS case commands accessed an internal infrastructure document and the saved password store. Further consequences are not documented.
Severity
Moderate
Attribution
According to Elastic, attackers in confirmed intrusions used the applications to maintain access to endpoints. According to Help Net Security, this was misuse after attackers had already obtained access; the cases establish neither a vulnerability in the applications nor a compromise of the vendors. The attackers themselves are not named. (Attribution confidence: Medium)
Independent confirmation
None
Rationale of the assessment
Elastic, an independent security firm, reports on its own investigation of confirmed intrusions (primary source); the second source restates the same report and is not independent confirmation.
