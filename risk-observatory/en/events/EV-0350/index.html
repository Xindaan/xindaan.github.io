Apiiro: Claude Code stores secrets in settings file, thousands on GitHub

According to Apiiro, Claude Code saves the command including its secret to .claude/settings.local.json when users choose "Yes, and don't ask again"; the research found 2,539 real secrets in 1,994 public GitHub repositories.

Observed behaviour
According to Apiiro, Claude Code saves the command including its secret in the project folder, and nothing in the repository marks the file as private. In 539 of 1,105 traced repositories with a real secret, a commit co-authored by Claude changed the file; the commit instructions forbid committing .env or credentials.json but not this file. Of 104,185 public copies of the file, 1,122 held a real secret.
Demonstrated consequences
According to Apiiro, database passwords, cloud keys, API tokens and SSH root logins were exposed in public repositories; 63 organizations are affected, and one confirmed its key had been live. Actual abuse is not documented.
Severity
High
Attribution
Apiiro attributes the behavior to Claude Code; according to Apiiro, the head of Claude Code said on Hacker News on 7 November that no secret scrubbing is done and that the team is looking into prevention. (Attribution confidence: High)
Independent confirmation
Partial
Rationale of the assessment
