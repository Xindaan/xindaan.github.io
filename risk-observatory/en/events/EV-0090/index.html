Unit 42: actor used Hermes Agent with DeepSeek V4 for cybercrime

According to Unit 42, an actor used the Hermes Agent framework with DeepSeek V4 as its reasoning model, controlled via Telegram, with safety controls disabled.

Observed behaviour
According to Unit 42, the actor configured Hermes Agent with DeepSeek V4 and the Cursor IDE as a secondary tool, both with safety controls disabled. Several models were configured in Cursor, including Claude Opus 4.8 and GPT-5.5; which model actually ran is not established. The actor relied on AI-generated scripts and reconnaissance reports; a WordPress brute-force tool flagged one login as valid at a first Indian university. From a MongoDB database of a second Indian public university the actor exfiltrated more than 5,200 records.
Demonstrated consequences
According to Unit 42, more than 5,200 records containing personal data of students and faculty were exfiltrated from the second university. Whether the login at the first university was actually valid is not confirmed.
Severity
Moderate
Attribution
Unit 42 attributes the activity to a single actor and derives the AI use from the actor's configuration, scripts and reports. According to Unit 42, multiple unrelated actors are independently adopting the same Hermes + DeepSeek combination. (Attribution confidence: High)
Independent confirmation
None
Rationale of the assessment
The only source is the detailed report by Palo Alto Networks Unit 42 based on its own visibility into the actor’s working environment: a primary source, not a self-report. A second, independent source is missing, Unit 42 as a security vendor has a commercial interest, and text and figure leave the login success at the first university open. Hence MODERATE. Final rating after cross-check and fixed rules: moderate.

Methodological limitations
