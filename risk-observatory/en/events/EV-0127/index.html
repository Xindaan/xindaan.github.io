EV-0127Offensive cyber capabilities & misuseMisuse by humansReal-world effectEvidence quality: Low

SOCRadar: access broker uses Claude Code with 51 agents, data exfiltration in Ukraine

According to SOCRadar, as reported by The Hacker News, the Russian-speaking access broker CyberXero used Claude Code with 51 specialized agents for scanning, exploit chaining, reconnaissance and post-exploitation. According to The Hacker News, data was confirmed to have been exfiltrated from four Ukrainian organizations.

Observed behaviour
According to SOCRadar, as reported by The Hacker News, the operator used Claude Code with a cluster of 51 specialized agents. A single automated run scanned 4,708 targets, confirmed access to 429 WordPress administration panels and deployed 32 web shells within 61 seconds. To get around model refusals, the operator opened fresh sessions and framed the task as an authorized pentest on their own infrastructure. The logs also record refusals that held (backdoor, disabling a firewall, lateral movement, web shell).
Demonstrated consequences
According to The Hacker News, the campaign is estimated to have led to confirmed exfiltration from four Ukrainian organizations, harvesting more than 628,000 records tied to Ukrainian individuals.
Severity
High
Attribution
According to SOCRadar, as reported by The Hacker News, the activity is attributed to the Russian-speaking, financially motivated access broker CyberXero; according to SOCRadar, the sequence of events and the refusals come from analysing an exposed directory and the actor's logs. The sources contain no confirmation from Anthropic or the affected parties. (Attribution confidence: Medium)
Independent confirmation
None
Rationale of the assessment
Only The Hacker News's coverage of a SOCRadar report is available (one secondary source); the SOCRadar report itself has not been secured. The victim figures are phrased as an estimate, and independent confirmation is missing.
