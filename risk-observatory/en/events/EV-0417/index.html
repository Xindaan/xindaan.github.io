Anthropic's OSS Scanner reports vulnerability in Apache HTTP Server (CVE-2026-119618)

The Apache HTTP Server security page names "Anthropic's OSS Scanner" and two researchers from Google Cloud Vulnerability Research as finders of a mod_http2 flaw that, according to Apache, can lead to remote code execution. Fixed in version 2.4.71.

Observed behaviour
According to Apache, the flaw (in assign_headers() of mod_http2, versions 2.4.55 through 2.4.70) was reported by Anthropic on 26 October 2026 and by Google on 3 November and fixed on 11 November with version 2.4.71. According to Sysdig, Anthropic's OSS Scanner is an opt-in, model-driven scanner for open-source projects and reported the flaw eight days before the Google team. According to Sysdig, a public proof of concept showing the heap corruption appeared on GitHub on 12 November.
Demonstrated consequences
According to Sysdig, no confirmed in-the-wild exploitation has been reported. No harm is documented.
