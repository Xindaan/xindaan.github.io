EV-0059Offensive cyber capabilities & misuseMisuse by humansReal-world effectEvidence quality: High

AI agent ARTEX used in campaign against South Korean financial institutions

According to CrowdStrike, data was exfiltrated in a campaign against South Korean financial organizations (late September to early October 2026). Several security firms found traces of the open-source pentest agent ARTEX combined with other AI tools.

Mechanisms
ai assisted intrusiondata exfiltrationpentest agent misuse
Observed behaviour
CrowdStrike found configuration files, Claude Code session logs and agent contexts on attacker infrastructure; according to these, ARTEX used DeepSeek v4.1-flash as its primary model, and additional Claude Code sessions used GLM-5.3 and Grok 4.6 (according to Zscaler, the model names are not independently verified). According to Zscaler, the instructions told the AI to treat all targets as preauthorized; some settings allowed autonomous actions without approval per step. The prompts name targets in 19 countries and aim at personal data and phone numbers. According to Recorded Future, the actor (TAG-217) was testing infrastructure and assembling tools as early as August 2026.
Demonstrated consequences
Data was exfiltrated (CrowdStrike). According to Recorded Future, later public reporting indicated that personal data of at least 68,000 people at no fewer than seven financial institutions was exposed. According to Reuters, at least nine banks were reported as targeted. The ARTEX developer stopped public distribution and is converting the project to closed source.
Severity
High
Attribution
Human misuse of an AI agent. CrowdStrike and Zscaler independently document the use of the penetration-testing agent ARTEX together with Claude Code based on their own technical findings (CrowdStrike: configuration files, Claude Code session logs and agent contexts on attacker infrastructure; Zscaler: a Claude Code prompt history in an ARTEX installation of the attacker); Recorded Future tracks the actor as TAG-217 and found further attack tools on its infrastructure. CrowdStrike attributes the activity to no named adversary but considers a Chinese-speaking, financially motivated actor likely; according to Zscaler, the records likewise point to a Chinese-speaking operator. According to Zscaler, which models actually responded is not independently verified. (Attribution confidence: High)
Independent confirmation
Confirmed
Rationale of the assessment
Three mutually independent security firms (CrowdStrike, Zscaler, Recorded Future) consistently report the use of ARTEX based on their own technical findings; Reuters and BleepingComputer reported on it. Gaps: the number of affected people comes from later reports, the model names are not independently verified, and according to Recorded Future the extent of the AI contribution is not established.
