Outlook zero-day CVE-2026-124194: discovery credited by Microsoft to work with Claude

In its November 2026 Patch Tuesday, Microsoft lists an Outlook spoofing vulnerability as exploited in the wild. According to SecurityWeek, the advisory's acknowledgment credits a researcher using the moniker 'nono' and Benoît Sevens, mentioning Anthropic's Claude for Sevens. According to SOCRadar, CISA added the flaw to its Known Exploited Vulnerabilities catalog.

Observed behaviour
According to SOCRadar, when a crafted message file is opened, Outlook connects to an attacker-controlled network location without showing the external-content warning and thereby discloses the user's NTLMv2 hash. Microsoft lists the flaw (CVSS 6.5) as exploited. According to SecurityWeek, Microsoft's advisory credits a researcher using the moniker 'nono' and Benoît Sevens with the discovery; the acknowledgment for Sevens mentions the use of Anthropic's Claude AI model. SOCRadar and The Record likewise report that Microsoft credits the discovery to work with Claude.

Rationale of the assessment
Three reports (SOCRadar, SecurityWeek, The Record) agree, but for the AI involvement they trace back to the same origin, Microsoft's advisory, which is not itself archived. According to SOCRadar, CISA added the flaw to its Known Exploited Vulnerabilities catalog. Gaps: no information on victims, attackers or consequences.
