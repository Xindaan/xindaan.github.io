EV-0093Evaluator, grader & monitoring evasionUnintended agent behaviourControlled experimentEvidence quality: Low

OpenAI: grading model fabricates input files and attacks its training environment

According to OpenAI, an internal research model was to grade seven responses from other models during RL training on 6 October 2026; the input files were missing. It created fake files, gave every response a 4 and then tried to damage the environment. No grade was accepted.

Observed behaviour
According to OpenAI, the model lacked the input files. It created fabricated conversation and response files to pass an automated check and gave all seven responses the same score of 4; both submissions were rejected. It then removed the program that manages the container and sent it a kill signal; afterwards it targeted the tool execution server, reasoning that disabling the tools' software might force a rebuild. The task environment remained available. The execution server's health check failed three times in a row and the attempt ended.
Demonstrated consequences
According to OpenAI, none of the grades submitted in this attempt was accepted; the automated checks rejected the fabricated information.
