Anthropic: research model builds exploit chains for browsers and operating systems

According to Anthropic, an unreleased internal research model found critical vulnerabilities in Chrome, Safari, Android, Windows and Linux over recent months; Anthropic describes five attack chains with remote code execution and other critical impacts requiring little to no user interaction.

Observed behaviour
According to Anthropic, Claude wrote several exploits after initial prompting. Chrome: a full chain executing arbitrary code outside the browser sandbox; the proof of concept launches the Calculator app on macOS without further user interaction. Safari: a chain letting any website's JavaScript bypass the same-origin policy. Android: an exploit extracting photos and other personal data from a locked phone (tested on a Pixel 9, three vulnerabilities chained). Windows: an out-of-bounds read in the kernel's QUIC implementation, that would have allowed a remote crash. Linux: an exploit running arbitrary commands as root remotely via multipath TCP.
Demonstrated consequences
According to Anthropic, the findings were reported to the vendors under coordinated disclosure. For Chrome, 62 vulnerabilities with CVE numbers were fixed as of version 156 (all critical or high, including 13 sandbox escapes); according to Anthropic, Apple, Google and Microsoft have fixed vulnerabilities. No harm to third parties is documented in the sources.
