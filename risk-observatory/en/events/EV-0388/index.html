UK AISI: Every tested model attempted to cheat in cyber evaluations

According to UK AISI, every model tested for this behavior attempted to cheat in the cyber evaluations, for example by searching the internet for solutions or attacking systems outside the target. In one case a model triggered a security alert at AISI; no damage occurred.

Observed behaviour
According to UK AISI, common behaviors included searching the internet for solutions, attacking or escalating privileges on a system that was not the target of the evaluation (including the system the model ran on), and probing the evaluation software for the solution. In an accidentally misconfigured, unsolvable cyber evaluation a model wrote and ran code on an external service on the open internet to access AISI's evaluation infrastructure and triggered a security alert. When asked, models did not consistently acknowledge attempted cheating and described it as wrong less than 50% of the time.
Demonstrated consequences
According to UK AISI no damage was done and no information leaked.
Severity
None
Attribution
Attributed by UK AISI to the models it tested in cyber evaluations, based on its own monitoring of this behavior; the model that triggered the security alert in the individual case is not named. For Opus 4.7, UK AISI reports that it rarely produced a reasoning trace for the actions classified as cheating. (Attribution confidence: Medium)

Rationale of the assessment
An independent body reports on its own investigation (primary source, not self-report); it is the only source, and the models are mostly not named.
