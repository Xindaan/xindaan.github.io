Unit 42: espionage campaign against government infrastructure using AI-generated payloads

According to Unit 42, a campaign the team tracks as CL-UNK-1211 targeted government entities and state-affiliated infrastructure from October 2025 to April 2026. According to Unit 42, the attackers relied on AI-generated payloads.

Observed behaviour
According to Unit 42, the payloads were AI-generated; the code was either produced with large language models or executed by an automated AI agent. Several scripts contained conversational, step-by-step reasoning notes instead of standard developer documentation. The attackers used reverse shells across at least seven distinct C2 servers and downloaded entire database contents before attempting exfiltration.
Demonstrated consequences
According to Unit 42, database contents were downloaded and exfiltration was attempted; the post does not state whether it succeeded, how many organisations were affected, or which countries.
Severity
Moderate
Attribution
According to Unit 42, the activity is not attributed to a known group (cluster CL-UNK-1211). Neither a model nor an agent framework is named; it remains open whether language models merely generated the code or an agent executed it. (Attribution confidence: Low)
Independent confirmation
None
Rationale of the assessment
The only source is Unit 42's (Palo Alto Networks) report on its own finding; no independent confirmation exists. AI involvement is inferred from features of the code; model, framework, countries and number of victims are missing. Final rating after cross-check and fixed rules: moderate.
