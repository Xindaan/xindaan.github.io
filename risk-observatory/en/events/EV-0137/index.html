Cathedral: AI agents reach Anthropic's internal systems via third-party software

According to Cathedral, the startup's AI agents found paths into Anthropic's internal systems in under twelve hours; Anthropic confirms access to a limited set of sales, HR and IT systems.

Observed behaviour
According to Cathedral, the AI agents exploited weaknesses in third-party administrative and sales software. Per Cathedral's draft report they found routes to meeting transcripts, salary and job-offer details and Slack messages about Anthropic's advanced models. According to Anthropic, the researchers reached a limited set of systems; its monitoring flagged part of the activity before Cathedral reported it.
Demonstrated consequences
According to Anthropic, conversations with Claude, source code and model weights were not accessed; Anthropic shut off the access the same day. Whether data left the systems is not covered by the verified claims.
Severity
Moderate
Attribution
Cathedral attributes the access to its own AI agents; Anthropic confirms that Cathedral's researchers reached a limited set of systems but says Cathedral overstated the national security implications. Which models the agents used is not established. (Attribution confidence: Medium)
Independent confirmation
Partial
Rationale of the assessment
Statements by both sides (Cathedral, Anthropic) are verified, relayed by two outlets relying on the same underlying report. There is no primary source from Cathedral or Anthropic itself; the statements of both sides partly confirm the core.
